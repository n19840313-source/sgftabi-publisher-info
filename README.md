# 雪月風花の旅路

制作者用 TikTok 投稿支援ツール / 創作者自用 TikTok 上傳輔助工具

本ツールは、雪月風花の旅路（@sgftabi）の制作者が、自作の日本の城・社寺巡礼動画を自身の TikTok アカウントの下書きへアップロードし、本人が確認して投稿するためのデスクトップツールです。

現在は開発・Sandbox 設定段階です。一般向けサービスとして提供しておらず、新しい TikTok アプリのアカウント認可と動画アップロードはまだ完了していません。このページは公開説明文書であり、動画投稿や認可を実行するページではありません。

繁體中文：本工具供「雪月風花の旅路」創作者將自行製作的日本名城、社寺巡禮影片上傳至本人 TikTok 草稿，再由本人檢查及發布。目前仍在開發與測試設定階段，尚未完成新應用程式的帳號授權及影片上傳。

## Intended workflow

1. 制作者本人が TikTok の認可画面で対象アカウントと権限を確認します。
2. 自身が権利を保有する、または利用許諾を得た動画を選択します。
3. 明示的な操作により TikTok の下書きへ送信します。
4. TikTok 上で内容と公開設定を確認し、本人が投稿します。自動公開は行いません。

繁體中文：本人確認帳號與權限 → 選擇有權使用的影片 → 明確操作後上傳草稿 → 在 TikTok 檢查並自行發布。不自動公開。

## Privacy Policy

### 対象と開発状況

この方針は本ツールの TikTok 連携に適用します。以下は実装・運用時に守るデータ取扱方針です。新アプリの認可は未完了であり、認可済みのサービスであることを示すものではありません。

### 取得する情報と目的

予定する権限は user.info.basic、user.info.profile、video.upload です。認可された範囲でアカウント識別子、表示名、プロフィール画像やプロフィールリンクなどを取得し、接続先が本人の意図するアカウントであることの確認に使用します。投稿支援のため、本人が選択した動画と投稿に必要な情報を扱います。私信、連絡先、パスワードの取得は求めません。

### 保存と送信

認可情報は本人の Windows 端末で暗号化して保管する方針です。アクセストークンやアプリの秘密鍵をこの公開リポジトリへ保存しません。選択した動画と必要な情報は、本人のアップロード操作時に TikTok へ送信します。アカウント情報を広告目的で販売・提供しません。

TikTok に送信した情報の取扱いには TikTok の方針が適用されます。この説明ページのホスティングには GitHub を使用しており、ページ閲覧時の GitHub によるデータ取扱いは GitHub のプライバシー方針に従います。

### 保存期間・解除・削除

ローカルの認可情報は連携が必要な期間のみ保持し、連携を終了する場合は TikTok 側で認可を解除し、本ツールのローカル保存情報を削除します。ローカル情報の削除だけでは TikTok 上の下書きや投稿は削除されません。これらは TikTok 上で別途管理してください。

### 問い合わせ

本リポジトリの Issues で、機密情報を含まない一般的な問い合わせを受け付けます。Issue は公開されるため、トークン、パスワード、非公開動画、個人情報は記載しないでください。
